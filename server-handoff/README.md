# Передача на сервер компании

Эта папка нужна, чтобы другой Claude, подключённый к серверу компании, установил и запустил портал. Разработка кода закончена до этой точки; на сервере остаётся только установка.

| Файл | Для кого | Что внутри |
|---|---|---|
| [PROMPT.md](PROMPT.md) | для владельца | Готовый текст: заполнить поля и вставить в чат Claude на сервере |
| [handout.md](handout.md) | для ИТ и для Claude на сервере | Всё в одном файле: состав и состояние, подготовка, установка, проверка, ошибки, эксплуатация, приёмка |
| README.md | для всех | Это объяснение |

## Что делать владельцу

1. Передать ИТ [handout.md](handout.md) и архив `release-package` из зелёного CI на `main`: на сервер ставится только он.
2. Заполнить поля в [PROMPT.md](PROMPT.md): адрес сайта, IP, сети, сертификат, имя администратора, место для копий.
3. Вставить текст в чат Claude на сервере.

Пароли, приватный ключ TLS и recovery-ключ в чат и в репозиторий не вставлять.

## Как устроен портал

Один Linux-сервер, Docker Compose, пять постоянных контейнеров:

| Контейнер | Задача | Доступ снаружи |
|---|---|---|
| `proxy` (Nginx) | HTTPS, список разрешённых сетей, лимиты | да, один порт HTTPS на частном IP |
| `app` (Django + готовый React) | сайт и API | нет |
| `worker` (Python) | проверка файлов, OCR | нет |
| `postgres` 17 | база | нет |
| `clamav` | антивирус | нет, сам ходит за сигнатурами |

Установкой управляет `portalctl` (Python, без зависимостей). Он создаёт секреты, собирает образы, делает миграции, запускает всё, прогоняет живую проверку (чистый файл, тестовый вирус EICAR, OCR, HTTPS) и делает первую зашифрованную копию. Если хоть одна проверка не прошла, вход на сайт закрывается и установка считается неуспешной.

На сервере нет Node.js и npm: интерфейс собирает GitHub CI ([ADR 004](../docs/adr/004-no-node-on-server.md)).

## Что исправлено в 0.3.0-rc.13

Последствия в средней колонке выведены из чтения кода, на сервере они не воспроизводились. Режим 0600 в ZIP подтверждён отдельно на стандартной библиотеке Python.

| Проблема | К чему приводит на сервере | Исправление |
|---|---|---|
| Упаковщик писал файлы в ZIP с правами 0600 | После `unzip` от root контейнеры (uid 10001 и postgres) не могут прочитать код и скрипт ролей: установка падает | Явные права в архиве; `portalctl` перед сборкой проверяет права файлов релиза, `.deploy` не трогает |
| Проверка готовности читала stdin | `install --password-stdin` теряет пароль: установка падает на создании администратора | Проверки запускаются с закрытым stdin |
| Nginx запоминал адрес `app` один раз | После перезапуска API сайт может отвечать 502 до ручного перезапуска Nginx | Адрес переспрашивается у Docker DNS каждые 10 секунд |
| ClamAV ограничен 3 ГиБ | При обновлении сигнатур в памяти две базы: возможна остановка по памяти | Лимит 4 ГиБ |
| Символ NUL или битый Unicode в тексте PDF | PostgreSQL отклоняет запись, документ около часа висит в обработке и завершается ошибкой | Текст очищается в worker и в API |
| Путь запроса длиннее 80 символов в аудите | Отказ в правах отдаёт 500 вместо 403 (доступ при этом не открывается) | Значение обрезается |
| Названия на пределе длины с символами вроде «№» | Ошибка 500 при сохранении | Поисковое поле обрезается до размера колонки |
| CI не собирал образ PostgreSQL и не проверял Nginx и права архива | Такие ошибки видны только на сервере | Новые проверки в CI; ручной запуск `workflow_dispatch` |

## Известные ограничения

- Репозиторий **публичный**. Секретов в нём при проверке не найдено, но это внутренний портал компании: рекомендуется сделать репозиторий закрытым.
- При стандартном режиме входа (без обязательной смены пароля) в интерфейсе нет кнопки «сменить пароль»; пароль сбрасывает администратор.
- Нужен прямой выход в интернет для Docker Hub, Alpine, PyPI, GitHub и ClamAV. Корпоративный HTTP-прокси загрузчики исходников намеренно не используют.
- PDF с действием при открытии (`/OpenAction`), JavaScript или вложениями отклоняются: это политика безопасности, а не ошибка.
